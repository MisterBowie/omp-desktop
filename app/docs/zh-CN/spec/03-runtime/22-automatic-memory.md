# OMP 自动记忆

本文同步自[英文源规格](/spec/03-runtime/22-automatic-memory)。

入口为“设置 → 记忆”。“自动保存”和“自动读取”分别控制，默认均关闭。
关闭保留已有内容，手动项目记忆、聊天记录与原生 CLI 的数据独立保留。

记忆由 OMP 的 Mnemopi 管理，按会话的实际工作目录隔离，worktree 独立。
数据库保存在 OMP Desktop 数据目录，不随临时运行目录清理。保存开启后
只处理后续消息；清空或恢复旧会话也不会重新导入旧历史。

页面支持选择项目或 worktree 会话、分页查看、文本搜索、刷新和清空。
清空需要再次确认，确认绑定到当前选择；切换项目会忽略旧请求结果。
当前使用本地文本检索，不下载向量模型。记忆提炼使用会话配置的模型，
可能产生额外 Token；Auto-Learn 继续关闭。

有运行中的会话、子代理、后台命令或待投递结果时，不能更改记忆或清空。
维护期间新消息等待，完成后继续唤醒排队跟进。旧运行时缺少记忆接口时
会拒绝开启，避免界面显示成功但实际不生效。

Rust 宿主保存两个布尔设置；OMP 是记忆数据库的唯一读写方。
桌面通过独立、无凭证的管理进程调用结构化 RPC，不读取终端文本，
渲染层不直接访问数据库。管理进程不调用真实模型，退出时负责回收。
