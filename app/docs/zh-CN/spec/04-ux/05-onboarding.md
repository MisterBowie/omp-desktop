# 05. 新手引导

> **翻译说明：** 本页是与 [英文源规格](/spec/04-ux/05-onboarding) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。


## 1. MVP 的决策

使用**内联首次运行清单**，而不是多页模式向导。

理由：

- 更快地获得第一个值
- 更少的阻塞
- 更容易使用 skip/return

## 2. 首次运行检测

当满足以下任一条件时显示检查表：

1. 没有配置提供商
2.默认提供商没有秘密存在
3. 尚无会话存在

保留解雇状态，但不完整的关键步骤可能会重新显示为横幅。

## 3. 检查清单步骤

1. **添加提供商**
2. **保存 API 密钥**
3. **打开项目文件夹**
4. **发送您的第一个提示**
5. *（可选）* 加载开发插件

## 4. 安置

- 显示在主聊天空白状态
- 提供商和关键项目深层链接至“设置”→ Agent
- 可选插件项打开应用程序外壳的插件目的地
- 项目和提示项调用其相关的应用程序操作
- 核心步骤完成后清单会崩溃

## 5. 复制提示音

英文源码，简洁，行动导向。

示例：

- “添加模型提供商”
- “保存您的 API 密钥”
- “打开项目以启用本地工具”

## 6. 非目标

- 帐户注册
- 云同步设置
- 长产品巡演覆盖
- 为回访用户提供强制教程

## 7. 验收

1. 新鲜的个人资料显示清单
2. 完成provider+key+prompt删除关键的空状态拦截器
3. 用户可以在不中断应用程序使用的情况下关闭可选部分
