# OMP 会话 worktree 源码验收摘要（2026-10-18）

本地 OMP 隔离会话支持创建、恢复、预览合并、同步、显示目录及删除。配置项目身份和实际执行根分离，文件面板与聊天链接使用工作树，A→B→A 的迟到文件读取不会覆盖当前结果。schema 21→22 升级先备份；回退旧版需要恢复备份。自动初始化/include/端口/子代理独立工作树及后台命令未实现。

643 host-core、345 相关桌面、556 OMP、497 shared 源码、25 i18n 用例通过，两个真实原生流程通过。协议烟测 23 通过、2 个真实模型明确跳过。重复执行不累加为独立用例。

这是可公开的验收摘要，详细本机记录保留在原工作分支，不随发布上传。
本阶段当时仅为源码验收；0.1.1 的正式构建和发布状态以[发布记录](Version-011-release-20261019.md)为准。
