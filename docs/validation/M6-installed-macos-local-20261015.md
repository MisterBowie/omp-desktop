## 实际路径和结果

验收程序只读挂载实际 DMG，通过系统 `ditto` 将真实 `.app` 复制到自有、包含中文/空格/单引号的临时安装目录。随后从其真实可执行文件启动，先由 Main inspector 核对 `app.isPackaged=true`、名称、版本、arm64、resources/executable/profile/home；只连接该 Main 所拥有的主渲染窗口，不连接隐藏插件窗口。

启动环境为封闭白名单，PATH 只有自有空目录；未传开发 host/runtime override、capture 启动模式或数据目录覆盖参数。应用自行选中自有 HOME 下 `.omp-desktop`，两个真实启动均核对一致。HOME 内预置的假 PI 数据库/文件型凭据及 OMP/规则文件未改写，未进入模型请求。

1. 公开 preload IPC 创建项目/本地提供方/OMP 会话，实际侧栏选择该会话。
2. 实际 Composer 发消息，原生 write 工具请求在真实审批卡前阻断；拒绝后原始文件逐字节不变。
3. 再次请求并批准一次后，目标文件精确变为预期内容；原生记录中两次 write 调用各一个唯一 ID、两条结果、一次拒绝失败和一次批准成功，无重复。
