## 边界

- 0.1.7 是更高版本号：已安装 0.1.6 及更早版本的用户会由应用内更新器收到 0.1.7（未签名 Mac 打开下载页手动安装）。
- 包未签名、未公证，首次安装可能需要在“系统设置 → 隐私与安全性”中放行。
- 全程没有真实付费模型请求。Windows、Linux、Mac Intel 的安装包由候选的原生构建与包内验收覆盖，没有在本机运行。
- 匿名 GitHub API 每小时 60 次：轮询候选时用尽过一次额度，之后改为读取公开网页，不影响结果。
